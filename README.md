# foo-fighter

A simple "Hello World" Angular application demonstrating CI/CD with Azure.

## Built With
- Angular 17.3
- TypeScript 5.4

## Development

### Prerequisites
- Node.js 18 or higher
- npm

### Installation
```bash
npm install
```

### Running the app locally
```bash
npm start
```

Navigate to `http://localhost:4200/` in your browser.

### Building for production
```bash
npm run build:prod
```

The build artifacts will be stored in the `dist/` directory.

## Azure Deployment

This application is configured to be deployed to Azure App Service. The built files in the `dist/` directory can be deployed directly to Azure.
